# Source attribution

This collection preserves a local Vega-Lite chart corpus and its frozen input
rows. Original specifications are stored byte-for-byte as
`charts/vl_####/source.vl.json`. Per-chart `metadata.json` lists authored data
URLs, file hashes and retained translation notes. `resolved-source.vl.json`
is the frozen self-contained input; original URL references remain in the
unaltered source file.

The original local corpus did not provide a corpus-wide license or canonical
repository URL. This repository does not assert a new license for third-party
specifications or data. Follow the original data providers' terms. The MIT
license covers the viewer and tooling.

- [Vega-Lite](https://github.com/vega/vega-lite) supplies the source grammar.
- [ggaction](https://github.com/ggaction/ggaction) supplies the translation runtime.
- Data-provider URLs, when authored in a chart, are recorded per chart.

No model requests, API keys, local credential files or private execution logs
are part of this distribution.
