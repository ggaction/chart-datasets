About the measures
G1 actions and options describe the first accepted program. Options are summed across actions, not a per-function maximum. Primary rows count the original primary data.json array before transformations; additional input tables are not included. Missing values sort last.
Types and structures are tags extracted from the original specification. A chart may belong to several groups. Translation stages share one canonical ggaction image; changing stage changes the code, not the chart.
